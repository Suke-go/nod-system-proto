# ACNの役割と接続判断

2026-09-19。ユーザーのACNは英語で学習済み。コピー済み原稿`work/acn_reference/interspeech_2026_acn/main.tex`と実装`acn/acn_v8_spectral.py`、`acn/acn_v9_textfeat.py`を確認した。ここでいう未接続は「モデルが学習されていない」という意味ではない。

## 主実験には必須ではない

主実験は意味観測からの応答機能推定と履歴保持の効果。ACNが推定する単語単位の知覚的な目立ちやすさは、意味理解・共感・感情の種類とは別の量である。意味が理解表示を支持するのにタイミング規則で抑制される問題も、ACNを接続するだけでは解決しない。

主実験では動作強度を機能ごとに固定し、ACNを条件間で混ぜない。これで履歴の効果に動作の強さの違いが混入するのを避けられる。

## 英語の身体表現を調べる追加実験には役割がある

仮説は「話者が強調した箇所に対応する頷きの強度調整が、受け止めてもらえた感覚や適切さを改善するか」。まず英語に限定する。

- 意味機能・発火時刻・動作回数を固定して、固定強度とACN連動強度を比較する。
- 必要なら強度の分布だけ同じにして時間対応を崩した条件を追加し、単なる強度のばらつきと発話との対応の効果を分ける。
- 強調度から共感・喜び・賛成を直接推定しない。大きな声をそのまま大きな動作に置き換えない。
- 日本語は別の妥当性検証を行うまで適用しない。英語の朗読での学習・評価から自然なプレゼンへの一般化も確認する。

## MLP以外に必要なもの

原稿には、単語長の対数・MFCC0の平均・MFCC2の標準偏差、前後の単語との対比、話者ごとの正規化が記載されている。語境界はMFAによる。テキスト特徴付き版にはngram表も必要。MLPが軽いことと、入力から反応までの遅延が短いことは同一ではない。

特に後続語を参照する設定は後続語の観測を待つ。オンラインで後続語がまだ存在しないことを、文末で語が存在しないマスクと同一扱いにしてはならない。片側だけに変える場合は別の推論条件として検証する。全録音から計算した話者統計をオンライン実験に流用すると未来の音声を参照するため、事前収録した校正発話か因果的な統計更新を設計する。

このPCの`nod/models`とコピーされた`work/acn_reference`では、ACNの学習済み重み・正規化統計を含む推論パッケージは確認できなかった。SSH先の学習済み資産の不存在を意味しない。推論接続には次が必要。

1. 使用版、ネットワーク形状、学習済み重み。アンサンブルなら各重みと集約法。
2. 特徴抽出条件と順序、正規化統計/新規話者への処理、テキスト版なら語彙・ngram表。
3. 対象語と参照語の境界・利用可能になった時刻、出力の尺度と動作強度への対応。
4. 既知入力と期待出力の小さな検証例。Python参照実装と接続側の一致を確認する。

現状は固定強度であることをログに残し、ACNを使ったという主張はしない。英語の追加実験として資産を揃えてから、モデル推論だけでなく語境界・後続語待ちを含む遅延を測定する。
