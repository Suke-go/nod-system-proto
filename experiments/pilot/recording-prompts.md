# 最初の録音セット

各クリップ12秒を目安に、前後に1秒程度の無音を入れてください。録音はCLIを実行した時だけ始まります。
本人の実体験である必要はありません。まず以下の架空の話を使い、同じ話題を通常／強調ありの2通りで録音すると比較できます。

1. 経路の説明: 駅を出て、左に曲がって、図書館まで行く方法を説明する。
2. 手順の説明: 資料を保存してから、メールで提出する手順を説明する。
3. 話の途中: 「昨日駅へ向かって歩いていて、それで途中に……」と続きを探す。
4. 言い直し: 「火曜日に、いや木曜日に提出します」と訂正する。
5. 喜び: 長く勉強してきた試験に合格できたという話。
6. 残念な出来事: 準備してきた発表が中止になったという話。
7. 意味の反転: 「合格したと思ったんですが、実は番号を見間違えていて」と続ける。
8. 具体化前: 「初めは順調だったんですが、その後で……」と内容がまだ分からない段階を作る。

名前は `s01_route_normal.wav`, `s01_route_emphasis.wav` のように条件を含めます。
比較時は同じWAV・同じtimelineを使い、設定ファイルやJevモデル版を分けて記録します。
このセットは動作確認用の台本であり、自然会話コーパスでも研究用の正解データでもありません。

人手評価では、録音を聞いて候補時刻ごとに以下を記録します:

- 返してよい時刻か、早すぎるか、遅すぎるか。
- 意味機能の候補（no_bc / continuer / understanding / empathic）。複数許容や不明もメモする。
- 表出の強さが適切か。現在ACN未接続なら強度条件として評価しない。
- 話者、台本、録音条件、評価者、評価日。

`cases.jsonl` のreference_labelは作成時の仮ラベルです。人が確認した項目だけlabel_statusをreviewedに変更します。
仮ラベルをそのまま「人手正解」として精度集計しません。
